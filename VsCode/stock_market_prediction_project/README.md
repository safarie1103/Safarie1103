
# Stock Market Prediction Project (Baseline + Neural Network + Real Data)

This project is a complete stock market prediction pipeline using:

- A Random Forest baseline model
- A Neural Network (MLP) model
- Technical indicators (RSI, MACD, Bollinger Bands, moving averages, volatility, lagged returns)
- Real stock data from Yahoo Finance via `yfinance`
- A simple long/flat backtest with transaction costs

See `src/train_baseline.py` and `src/train_mlp.py` for details.
